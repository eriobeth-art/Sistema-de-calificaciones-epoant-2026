Sincronización de estudiantes

Actualiza la base del sistema desde Datos de Identificación sin duplicar alumnos ni alterar su historial académico.

Automática: el sistema consulta la fuente maestra como máximo una vez cada 10 minutos. Sólo los registros con ESTATUS = ACTIVO se incorporan o permanecen activos. PENDIENTE y REVISAR no se habilitan.
La sincronización manual permite aplicar inmediatamente cualquier alta o cambio realizado en Datos de Identificación.

Integridad de vínculos

Comprueba que cada reporte, firma y seguimiento corresponda al ID y nombre del estudiante correcto.

V3.0 valida por ID_ESTUDIANTE y, para firmas, también por folio, FILE_ID, versión y huella del reporte. Las firmas antiguas sin vínculo exacto ya no se presentan como firma del reporte vigente.
Ejecuta la verificación cuando quieras revisar la integridad del sistema.
